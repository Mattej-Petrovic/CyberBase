# CyberBase

Features

- Command Library: Searchable, copy‑ready commands (minimal usage, flags, examples).
- Tools Explorer: CLI/GUI/Detection tools with detail pages and GUI cheat sheets.
- Concepts: Frameworks & standards, principles & identity, networking & protocols, ports (with learn sections).
- Defend: Detection/logging guides and hardening checklists.
- Log Analyzer: Upload or paste logs to detect risky patterns; JSON API supported.
- Quiz: Topic‑based questions with answer reveal and randomized sets.
- Global Search: Unified results across commands, tools, concepts, ports, and defend.
- Auth & Roles: Firebase authentication with session cookies; admin‑only dashboard.
- AI Assistant: Contextual help and command explanations via the in‑app drawer.
